# AI-Resume-Analyzer-and-Skill-Recommendation-System

An AI-powered web application that analyzes resumes, identifies existing skills, highlights skill gaps, and provides personalized career recommendations using Google's Gemini AI. The system helps students and job seekers improve their resumes and align their skills with industry requirements.

## Features

* Resume upload (PDF format)
* Automatic text extraction from resumes
* AI-powered resume analysis using Gemini API
* Skill identification and gap analysis
* Personalized skill recommendations
* Career improvement suggestions
* Downloadable analysis reports
* MongoDB-based report storage
* Responsive and user-friendly interface

## Tech Stack

### AI Integration

* Google Gemini API

### File Processing

* Multer
* PDF-Parse

## Project Workflow

1. User uploads a resume.
2. Resume text is extracted from the PDF.
3. Gemini AI analyzes the resume content.
4. The system identifies skills and missing competencies.
5. Personalized recommendations are generated.
6. Analysis results are stored in MongoDB.
7. Users can view and download the report.

## Key Benefits

* Helps improve resume quality
* Identifies missing industry-relevant skills
* Provides learning and career guidance
* Supports students, freshers, and professionals
